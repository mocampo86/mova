# Glossary

| Term | Definition |
|------|------------|
| **Complex** | Short for **Sports Complex**. A facility that has one or more courts and is managed by administrators. |
| **Court** | A physical or logical playing area inside a complex (e.g. a football field, a padel court). |
| **Sport** | A type of activity that can be practiced on a court (e.g. football, tennis, padel). |
| **Availability Rule** | A configuration that defines when a court is available on a specific day of the week, including start/end time and slot duration. |
| **Business Hours** | The opening hours of a complex on a specific day of the week. |
| **Reservation** | A booking of a court by a user for a specific time range. |
| **Recurring Reservation** | A rule that generates weekly reservations over a defined period. |
| **Occurrence** | A single generated reservation that belongs to a recurring reservation series. |
| **Court Block** | A manual block that prevents reservations on a court during a time range. |
| **Blocked User** | A user who has been blocked by an administrator of a specific complex. |
| **Slot** | A discrete bookable time interval on a court, defined by `SlotDurationMinutes`. |
| **User** | Any registered person using the platform. |
| **Complex Administrator** | A user authorized to manage one or more complexes. |
| **Super Administrator** | A platform operator with global access. |
| **Audit Log** | A record of administrative actions for compliance and troubleshooting. |
| **MVP** | Minimum Viable Product. The smallest version that validates the core value proposition. |
