# US-059 — Change application language from the main screen

## Status

Ready

## Objective

As a visitor, I want to change the application language from the main screen so all pages display in Spanish, English, or Portuguese.

## Functional description

This user story enables the visitor to change the application language from the main screen. It belongs to EPIC-11 — Internationalization and Language Support.

## Acceptance criteria

- [ ] Change application language from the main screen is implemented and available to the visitor.
- [ ] A language selector is visible on the main/public screen.
- [ ] Selecting Spanish, English, or Portuguese updates the language of all pages immediately.
- [ ] The selected language is applied globally, not just on the current page.
- [ ] All existing public and authenticated pages use translated strings.
- [ ] Fallback to English or browser language when an unsupported language is requested.

## Business rules

- Spanish (`es`), English (`en`), and Portuguese (`pt`) are the supported languages for the MVP.
- The language selector must be reachable from the main/public screen.
- Translation files must be structured to make adding future languages straightforward.

## Validations

- Validate that only supported language codes are accepted.
- Fallback gracefully if a translation file is missing or fails to load.

## Error cases

- Invalid or missing language code.
- Translation file for the selected language is missing or fails to load.

## Security considerations

- Do not expose internal implementation details in error responses.
- Avoid logging PII when persisting language preference.

## Technical notes

- Recommended library: `react-i18next` with `i18next`.
- Store translation files under `src/mova-web/src/locales/{lang}.json` or similar.
- Use locale codes `es`, `en`, `pt`.
- Wrap app with `I18nextProvider` in `providers.tsx`.
- Update `PublicLayout` to include the language selector.
- Initialize i18n before rendering the app.

## Tests required

- **Unit**: language context/hook logic and locale fallback.
- **Integration**: selector interaction updates page text.
- **E2E**: user changes language and navigates across pages.

## Out of scope

- Right-to-left (RTL) language support.
- Server-side user profile language preference.
- Translation management UI or CMS.

## Dependencies

- EPIC-01 — Technical Foundation.
- EPIC-09 — Landing Page and Public Site.

- All acceptance criteria are implemented and verifiable.
- Relevant unit, integration, and E2E tests pass.
- Code review is approved.
- No secrets or sensitive data are committed.
- Documentation is updated if the change affects setup or API contracts.
