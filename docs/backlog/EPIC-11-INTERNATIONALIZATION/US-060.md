# US-060 — Display language selector with a flag or language icon

## Status

Done

## Objective

As a visitor, I want the language selector to display a flag or language icon so I can identify languages visually.

## Functional description

This user story enables the visitor to see a flag or language icon in the language selector. It belongs to EPIC-11 — Internationalization and Language Support.

## Acceptance criteria

- [ ] Display language selector with a flag or language icon is implemented and available to the visitor.
- [ ] The selector shows a flag, language icon, or locale label for each option.
- [ ] The selector is accessible (keyboard navigable, screen-reader friendly).
- [ ] The selected language is visually highlighted.
- [ ] The design is responsive on mobile and desktop.

## Business rules

- Each supported language has a visual identifier (flag or icon).
- Spanish, English, and Portuguese options are supported.
- The component must be reusable and extensible for future languages.

## Validations

- Validate that icons/assets exist for each supported language.
- Fallback to text label if an icon asset is missing.

## Error cases

- Icon asset missing for a supported language.

## Security considerations

- Prefer local SVG or emoji flags; avoid fetching icons from external CDNs without integrity checks.
- Do not embed external URLs that could change or be blocked.

## Technical notes

- Use MUI `Select` or `Menu` with `ListItemIcon` and `ListItemText`.
- Options for icons:
  - Emoji flags (`🇪🇸`, `🇬🇧`, `🇵🇹`) — simplest, no extra dependency.
  - Local SVG flag icons — lightweight, no network request.
  - Approved icon library if architect/security signs off.
- Keep icon assets under `src/mova-web/src/assets/flags/` or similar.
- The component should be placed in the shared layout/shell.

## Tests required

- **Unit**: component rendering and selected state.
- **Integration**: selector interaction updates the active language.
- **E2E**: visual and accessible behavior.

## Out of scope

- Custom icon design or animated flags.
- External icon CDN dependencies.

## Dependencies

- EPIC-01 — Technical Foundation.
- EPIC-09 — Landing Page and Public Site.
- US-059 — Change application language from the main screen.

- All acceptance criteria are implemented and verifiable.
- Relevant unit, integration, and E2E tests pass.
- Code review is approved.

- Documentation is updated if the change affects setup or API contracts.
