# US-078 — Admin panel displays the language selector

## Status

Done

## Objective

As an admin, I want the language selector to be available in the admin panel so I can use the admin pages in my preferred language.

## Functional description

This user story adds the language selector to the admin panel layout, ensuring all admin pages can be switched between Spanish, English, and Portuguese. It belongs to EPIC-11 — Internationalization and Language Support.

## Acceptance criteria

- [x] Admin panel displays the language selector is implemented.
- [x] The language selector is visible on all admin pages.
- [x] Selecting Spanish, English, or Portuguese updates the language of admin pages immediately.
- [x] The selected language is applied globally, including public, user, and admin pages.
- [x] The selector shows a flag, language icon, or locale label for each option.
- [x] The selector is accessible (keyboard navigable, screen-reader friendly).
- [x] No hard-coded UI text remains on admin pages covered by this epic.

## Business rules

- Spanish (`es`), English (`en`), and Portuguese (`pt`) are the supported languages for the MVP.
- The admin panel must reuse the existing `LanguageSelector` component.
- Admin language selection shares the same persisted preference as public and user pages.
- Translation files must cover all admin UI strings.

## Validations

- Validate that only supported language codes are accepted.
- Fallback to the existing application fallback language if a translation is missing.

## Error cases

- Invalid or missing language code.
- Translation file for the selected language is missing or fails to load.

## Security considerations

- Do not expose internal implementation details in error responses.
- Avoid logging PII when persisting language preference.

## Technical notes

- Add the existing `LanguageSelector` component to the `AdminLayout`.
- Reuse the i18n setup and locale files from US-059, US-060, and US-061.
- Add or complete translation keys for the admin namespace/sections.
- Keep locale codes consistent (`es`, `en`, `pt`).

## Tests required

- **Unit**: `LanguageSelector` renders in the admin layout.
- **Integration**: selecting a language updates admin page text.
- **E2E**: admin user changes language and navigates across admin pages.

## Out of scope

- Right-to-left (RTL) language support.
- New languages beyond `es`, `en`, `pt`.
- Server-side user profile language preference.

## Dependencies

- EPIC-01 — Technical Foundation.
- EPIC-12 — Complex Admin Dashboard.
- US-059 — Change application language from the main screen.
- US-060 — Display language selector with a flag or language icon.
- US-061 — Persist language preference and detect browser language.

- All acceptance criteria are implemented and verifiable.
- Relevant unit, integration, and E2E tests pass.
