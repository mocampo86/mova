# US-061 — Persist language preference and detect browser language

## Status

Done

## Objective

As a user, I want my language preference to persist and be detected from my browser so I don't have to reselect it.

## Functional description

This user story enables the application to remember the selected language and detect the browser language on first visit. It belongs to EPIC-11 — Internationalization and Language Support.

## Acceptance criteria

- [x] Persist language preference and detect browser language is implemented.
- [x] The selected language persists across browser sessions.
- [x] The application detects the browser language on first visit when no preference is stored.
- [x] If the browser language is not supported, the application falls back to English.
- [x] Changing the language updates the persisted preference immediately.

## Business rules

- Language preference is stored locally if the user is not authenticated.
- If a future user profile includes language, server-side preference takes precedence after login.
- Supported browser language codes must be mapped to supported application locales (`es`, `en`, `pt`).

## Validations

- Validate that the stored language code is one of the supported values.
- Ignore and reset invalid persisted values to the fallback language.

## Error cases

- Corrupted or invalid stored language value.
- Browser language not supported.
- Local storage unavailable.

## Security considerations

- Store only the locale code; do not persist PII.
- Sanitize any stored value before using it.

## Technical notes

- Use `i18next-browser-languagedetector` with `localStorage` order.
- Alternatively, use a custom hook with `localStorage` and a context provider.
- Detection order suggestion: `localStorage` → `navigator` → `querystring` → `htmlTag` → fallback `en`.
- Keep locale codes consistent (`es`, `en`, `pt`).

## Tests required

- **Unit**: persistence logic and detection fallback.
- **Integration**: selector updates stored value and reloads with correct language.
- **E2E**: first visit detects browser language; subsequent visits use stored preference.

## Out of scope

- Server-side user profile language preference.
- Synchronization across devices.

## Dependencies

- US-059 — Change application language from the main screen.
