# US-049 — See how to find and book a court

## Objective

As a player, I want to see how to find and book a court.

## Functional description

This user story enables the player to see how to find and book a court. It belongs to EPIC-09 — Landing Page and Public Site.

## Acceptance criteria

- [ ] See how to find and book a court is implemented and available to the player.
- [ ] Results are filtered and paginated when applicable.
- [ ] Only active and public resources are returned to unauthorized callers.
- [ ] Response times remain acceptable for mobile users.
- [ ] The landing page loads quickly and is responsive on mobile.
- [ ] Sections clearly target players and owners.
- [ ] Featured complexes are pulled from active public data.
- [ ] Login and admin access are visible and functional.
- [ ] Basic SEO tags (title, meta description, Open Graph) are present.

## Business rules

- Public home page.
- Explanation of how the platform works.
- Section for players (users).
- Section for owners (complexes).
- Featured complexes.
- User login / profile access.
- Admin access.
- Responsive and SEO-friendly design.

## Validations

- Validate required fields and data types server-side.
- Validate query parameters and pagination inputs.
- Return clear, structured error messages for invalid input.

## Error cases

- Invalid or missing input data.
- User is not authenticated or authorized.
- The referenced resource does not exist.
- No results match the filter criteria.

## Security considerations

- Authenticate and authorize every mutating request.
- Do not expose internal implementation details in error responses.
- Avoid logging sensitive data such as passwords, tokens, or PII.
- Ensure users can only view data they are allowed to access (multi-tenancy).

## Technical notes

- Use React Router for public routes.
- Lazy load below-the-fold content where beneficial.
- Implement a `PublicLayout` separate from `UserLayout` and `AdminLayout`.
- SEO can be static for the MVP; dynamic rendering is future work.
