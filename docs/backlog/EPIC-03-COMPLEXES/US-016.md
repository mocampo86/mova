## Status

Ready

## Objective

As a super administrator, I want to see all complexes and activate/deactivate them if necessary.

## Functional description

This user story enables the super administrator to see all complexes and activate/deactivate them if necessary. It belongs to EPIC-03 — Sports Complex Administration.

## Acceptance criteria

- [ ] See all complexes and activate/deactivate them if necessary is implemented and available to the super administrator.
- [ ] The resource status can be toggled between active and inactive.
- [ ] Inactive resources are excluded from public listings.
- [ ] Only authorized administrators can change the status.
- [ ] Inactive complexes are not listed publicly.
- [ ] Superadmins can list and manage all complexes.

## Business rules

- CRUD for `SportsComplex`.
- Complex activation/deactivation.
- Public information configuration.
- Address and optional coordinates.
- Linking the first administrator to a complex.
- Superadmin moderation (preparation).
- Only authorized users can modify resources they own or administer.
