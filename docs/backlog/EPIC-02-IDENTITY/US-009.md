# US-009 — Complete my profile with my phone number

## Status

Done

## Objective

As a user, I want to complete my profile with my phone number so I can make reservations.

## Functional description

This user story enables the user to complete my profile with my phone number so that I can make reservations. It belongs to EPIC-02 — Identity and Access.

## Acceptance criteria

- [x] Complete my profile with my phone number is implemented and available to the user.
- [x] The profile form collects the required phone number.
- [x] Phone number is validated for format and stored.
- [x] Incomplete profiles are redirected to `/complete-profile`.

## Business rules

- Google OpenID Connect integration.
- JWT issuance and validation.
- User profile completion with mandatory phone number.
- Roles and authorization policies.
- Protected routes and endpoints.
- Preparation for future phone verification.

## Validations

- Validate required fields and data types server-side.
- Validate phone number format and required length.
- Return clear, structured error messages for invalid input.

## Error cases

- Invalid or missing input data.
- User is not authenticated or authorized.
- The referenced resource does not exist.

## Security considerations

- Authenticate and authorize every mutating request.
- Do not expose internal implementation details in error responses.
- Avoid logging sensitive data such as passwords, tokens, or PII.

## Technical notes

- Use ASP.NET Core `AddJwtBearer` and Google authentication.
- Store `GoogleSubjectId`, `Email`, `FullName`, `PhoneNumber`, and `PhoneVerified`.
- Backend endpoint: `PATCH /api/v1/users/me` accepts `phoneNumber` and returns updated `UserInfo`.
- Phone number is validated for international format (`+` followed by 7-15 digits, max 50 characters).
- Custom `IAuthorizationRequirement` for complex-scoped access.
- Frontend stores access token in memory and refresh token in `HttpOnly` cookie if implemented.
