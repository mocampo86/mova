# US-002 — React Application Scaffold

## Objective

As a developer, I want a React application scaffold so I can implement UI features.

## Functional description

Set up a Vite-based React application using TypeScript, MUI, TanStack Query, React Router, React Hook Form, and Zod. The scaffold must build, lint, and have a clear folder structure for pages, components, hooks, services, and utilities.

## Acceptance criteria

- [ ] A Vite + React + TypeScript project exists.
- [ ] Material UI is installed and wrapped in a theme provider.
- [ ] React Router is installed and configured with at least a basic route.
- [ ] TanStack Query (React Query) is installed and wrapped in a query client provider.
- [ ] React Hook Form and Zod are installed.
- [ ] `npm ci` completes without errors.
- [ ] `npm run build` produces a production bundle without errors.
- [ ] `npm run lint` passes when linting is configured.
- [ ] A clear folder structure exists (e.g., `components`, `pages`, `hooks`, `services`, `utils`, `types`).

## Business rules

- Use TypeScript strict mode matching the project configuration.
- Follow the naming conventions and folder structure defined for the project.
- Keep the dependency set aligned with the architecture decisions.

## Validations

- Run `npm ci` in the frontend directory.
- Run `npm run build` and verify no errors.
- Run `npm run lint` if configured.

## Error cases

- TypeScript or Vite configuration errors break the build.
- Missing peer dependencies break `npm ci`.
- Lint errors fail the build or the lint script.

## Security considerations

- Do not commit `.env` files with secrets.
- Do not hardcode API keys or credentials in source code.
- Review installed packages for known vulnerabilities when possible.

## Technical notes

- Vite + React + TypeScript.
- MUI, TanStack Query, React Router, React Hook Form, Zod.
- Configure `tsconfig.json` with strict settings.

## Tests required

- **Unit**: not applicable while scaffolding.
- **E2E**: not applicable while scaffolding.

## Out of scope

- API integration and data fetching logic.
- Authentication UI and protected routes.
- Business-specific pages and components.

## Dependencies

- US-001 — Runnable .NET Solution (backend exists to align structure and contracts).

## Definition of Done

- All acceptance criteria are met.
- Build and lint pass.
- Folder structure is accepted in review.

## Project affected

Frontend React application (`src/reservacanchas-web` or equivalent).

## Suggested branch

`feature/US-002-react-scaffold`

## Instructions for Devin

Scaffold the React application with the specified libraries, configure build and lint scripts, define the folder structure, and run `npm run build` and `npm run lint`. Do not implement feature logic.
