# US-065 — Activate or deactivate complex from admin panel

## Status

Done

## Objective

As a complex administrator, I want to activate or deactivate my complex from the admin panel so I can control public visibility.

## Functional description

This user story enables the complex administrator to toggle the active status of their sports complex from the admin dashboard. It belongs to EPIC-12 — Complex Admin Dashboard.

## Acceptance criteria

- [ ] Toggle complex status is implemented and available at `/admin/complex/:complexId/profile`.
- [ ] The resource status can be toggled between active and inactive.
- [ ] Inactive resources are excluded from public listings.
- [ ] Only authorized administrators can change the status.
- [ ] A confirmation dialog is shown before deactivation.
- [ ] `UpdatedAt` is refreshed after a successful update.

## Business rules

- Complex activation/deactivation.
- Public information configuration.
- Only authorized users can modify resources they own or administer.

## Validations

- Validate required fields and data types server-side.
- Verify the actor has permission to update the resource.
- Return clear, structured error messages for invalid input.

## Error cases

- Invalid or missing input data.
- User is not authenticated or authorized.
- The referenced resource does not exist.

## Security considerations

- Authenticate and authorize every mutating request.
- Do not expose internal implementation details in error responses.
- Avoid logging sensitive data such as passwords, tokens, or PII.
- Verify the actor belongs to or administers the affected complex.

## Technical notes

- Use `PATCH /api/v1/complexes/{complexId}/status`.
- Reuse `UpdateComplexStatusRequest` and `UpdateComplexStatusCommandValidator`.
- Show a Material-UI `Dialog` for deactivation confirmation.
- Implement alongside the profile page or as a dedicated status control.

## Tests required

- **Unit**: status toggle logic and confirmation behavior.
- **Integration**: API endpoint behavior and persistence.
- **E2E**: admin activates and deactivates their complex.

## Out of scope

- Advanced analytics, reporting, or notifications not required for the MVP.

- US-064 — Edit complex profile from admin panel.
