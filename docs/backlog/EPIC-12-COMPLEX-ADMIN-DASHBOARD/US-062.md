# US-062 — View Complex Admin Dashboard overview

## Status

Ready

## Objective

As a complex administrator, I want a dashboard home page so I can see the status of my complex at a glance.

## Functional description

This user story enables the complex administrator to land on a dashboard overview that summarizes the most relevant information of the sports complex they administer. It belongs to EPIC-12 — Complex Admin Dashboard.

## Acceptance criteria

- [ ] Dashboard overview is implemented and available at `/admin/complex/:complexId`.
- [ ] Overview shows complex name, status, and last update.
- [ ] Overview displays the count of active and inactive courts.
- [ ] Overview displays a summary of today's reservations (confirmed, cancelled, completed).
- [ ] Overview displays the count of currently blocked users.
- [ ] Summary cards link to their respective admin sections.
- [ ] Only authenticated and authorized complex administrators can view the dashboard.
- [ ] Unauthorized access redirects to `/unauthorized`.

## Business rules

- Administrators can only view data for complexes they administer.
- Overview data is read-only and aggregated from existing domains.
- Inactive complexes still show in the admin dashboard.

## Validations

- Validate the user is authenticated and authorized as a complex administrator.
- Validate the referenced complex exists and belongs to the actor.
- Return clear, structured error messages for invalid input.

## Error cases

- User is not authenticated or authorized.
- The referenced complex does not exist.
- User does not administer the requested complex.

## Security considerations

- Authenticate and authorize every request.
- Do not expose internal implementation details in error responses.
- Avoid logging sensitive data such as tokens or PII.
- Verify the actor belongs to or administers the affected complex.

## Technical notes

- Reuse `GET /api/v1/complexes/{complexId}` for complex details.
- Consider adding `GET /api/v1/complexes/{complexId}/dashboard` to return aggregated metrics.
- Implement in `src/mova-web/src/pages/ComplexAdminPage.tsx` or a new `ComplexDashboardPage.tsx`.
- Use Material-UI cards, grid, and loading skeletons.
- Support responsive layout.

## Tests required

- **Unit**: summary aggregation and presentation logic.
- **Integration**: API endpoint behavior and dashboard page rendering.
- **E2E**: admin views dashboard, cards link to correct sections.

## Out of scope

- Advanced analytics, charts, or reporting.
- Real-time updates or notifications.
