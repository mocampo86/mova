# US-064 — Edit complex profile from admin panel

## Status

Done

## Objective

As a complex administrator, I want to edit my complex profile from the admin panel so it is always up to date.

## Functional description

This user story enables the complex administrator to edit the public profile of their sports complex from within the admin dashboard. It belongs to EPIC-12 — Complex Admin Dashboard.

## Acceptance criteria

- [ ] Edit complex profile is implemented and available at `/admin/complex/:complexId/profile`.
- [ ] The form pre-populates the current complex data.
- [ ] The existing resource is identified and updated.
- [ ] Input validation matches the rules used at creation.
- [ ] `UpdatedAt` is refreshed after a successful update.
- [ ] Only the owner or an authorized administrator can update the resource.
- [ ] Changes are reflected in public listings.

## Business rules

- CRUD for `SportsComplex`.
- Input validation must be enforced on the server, not only the client.
- Only authorized users can modify resources they own or administer.

## Validations

- Validate required fields and data types server-side.
- Enforce length, format, and range limits.
- Check uniqueness where applicable.
- Verify the actor has permission to update the resource.
- Return clear, structured error messages for invalid input.

## Error cases

- Invalid or missing input data.
- User is not authenticated or authorized.
- The referenced resource does not exist.
- Duplicate or conflicting data violates uniqueness rules.

## Security considerations

- Authenticate and authorize every mutating request.
- Do not expose internal implementation details in error responses.
- Avoid logging sensitive data such as passwords, tokens, or PII.
- Sanitize and validate all user input to prevent injection attacks.
- Verify the actor belongs to or administers the affected complex.

## Technical notes

- Use `PUT /api/v1/complexes/{complexId}`.
- Reuse `UpdateComplexRequest` contract and `UpdateComplexCommandValidator` rules.
- Implement form in `src/mova-web/src/features/admin/complex/profile/` or `src/mova-web/src/pages/ComplexProfilePage.tsx`.
- Use `react-hook-form` with `zod` resolver, following existing patterns.

## Tests required

- **Unit**: validation and form logic.
- **Integration**: API endpoint behavior and persistence.
- **E2E**: admin edits complex profile successfully.

## Out of scope

- Advanced analytics, reporting, or notifications not required for the MVP.
