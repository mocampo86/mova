# US-069 — Configure court sports, availability, and slot duration from admin panel

## Status

Done

## Objective

As a complex administrator, I want to configure a court's sports, availability rules, and slot duration from the admin panel.

## Functional description

This user story enables the complex administrator to assign sports and define availability rules for each court from the admin dashboard. It belongs to EPIC-12 — Complex Admin Dashboard.

## Acceptance criteria

- [ ] Sports assignment is implemented and available at the court detail/edit view.
- [ ] Availability rules per day of week are configured with start time, end time, slot duration, and active flag.
- [ ] Validates `StartTime < EndTime` and that slots fit within the range.
- [ ] A court must have at least one active sport before it can accept reservations.
- [ ] Only authorized administrators can configure the court.
- [ ] Changes are reflected in public availability queries.

## Business rules

- Association of one or more `Sport` to a court.
- `CourtAvailabilityRule` per day of week.
- Business hours can be configured per complex.
- Activation/deactivation of courts.
- Only authorized users can modify resources they own or administer.

## Validations

- Validate required fields and data types server-side.
- Validate `StartTime < EndTime` and that slots fit within the range.
- Verify the actor has permission to update the resource.
- Return clear, structured error messages for invalid input.

## Error cases

- Invalid or missing input data.
- User is not authenticated or authorized.
- The referenced resource does not exist.
- Availability rules are invalid or overlap incorrectly.

## Security considerations

- Authenticate and authorize every mutating request.
- Do not expose internal implementation details in error responses.
- Avoid logging sensitive data such as passwords, tokens, or PII.
- Verify the actor belongs to or administers the affected complex.

## Technical notes

- Use `PUT /api/v1/complexes/{complexId}/courts/{courtId}/sports`.
- Use `PUT /api/v1/complexes/{complexId}/courts/{courtId}/availability`.
- Reuse existing request contracts and validators.
- Use a table or accordion for day-of-week rules.
- Fetch available sports from `GET /api/v1/sports`.

- **E2E**: admin configures court sports and availability.
