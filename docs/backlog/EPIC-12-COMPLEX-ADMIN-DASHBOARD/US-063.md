# US-063 — Complex admin navigation layout

## Status

Ready

## Objective

As a complex administrator, I want a navigation layout so I can move between sections of my complex admin panel.

## Functional description

This user story provides a persistent navigation layout for the complex admin dashboard. It belongs to EPIC-12 — Complex Admin Dashboard.

## Acceptance criteria

- [ ] Navigation layout is implemented and wraps all `/admin/complex/:complexId/*` routes.
- [ ] Navigation shows links to Dashboard, Profile, Courts, Reservations, and Users.
- [ ] Active section is visually highlighted.
- [ ] Layout is responsive on mobile and desktop (collapsible drawer on mobile).
- [ ] Complex name or logo is displayed in the header.
- [ ] Unauthorized access redirects to `/unauthorized`.

## Business rules

- Only authenticated `ComplexAdmin` or `SuperAdmin` users can access the admin layout.
- Navigation links are scoped to the current `:complexId`.
- Layout persists when navigating between sections.

## Validations

- Validate the user is authenticated and authorized for the requested complex.
- Return clear, structured error messages for invalid input.

## Error cases

- User is not authenticated or authorized.
- The referenced complex does not exist.

## Security considerations

- Authenticate and authorize every request.
- Do not expose internal implementation details in error responses.
- Avoid logging sensitive data such as tokens or PII.

## Technical notes

- Create `ComplexAdminLayout.tsx` in `src/mova-web/src/layouts/`.
- Use `RequireComplexAdmin` as the auth guard.
- Use React Router `Outlet` to render nested routes.
- Use Material-UI `Drawer`, `AppBar`, `List`, and `ListItem` components.
- Update `src/mova-web/src/app/router.tsx` to nest admin routes under the layout.

## Tests required

- **Unit**: layout rendering and active link logic.
- **Integration**: navigation between sections.
- **E2E**: admin navigates through dashboard sections.

## Out of scope

- Custom themes or branding beyond the existing MUI theme.
- Breadcrumbs or advanced navigation patterns.

## Dependencies

- EPIC-02 — Identity and Access.
- `RequireComplexAdmin` component.
