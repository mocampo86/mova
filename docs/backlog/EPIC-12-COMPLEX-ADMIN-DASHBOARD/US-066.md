# US-066 — List courts from admin panel

## Status

Ready

## Objective

As a complex administrator, I want to list all courts of my complex from the admin panel so I can manage them.

## Functional description

This user story enables the complex administrator to view a paginated list of all courts belonging to their sports complex from the admin dashboard. It belongs to EPIC-12 — Complex Admin Dashboard.

## Acceptance criteria

- [ ] Court list is implemented and available at `/admin/complex/:complexId/courts`.
- [ ] The list shows court name, surface type, indoor/outdoor flag, status, and associated sports.
- [ ] Results are filtered and paginated when applicable.
- [ ] The list provides actions to create, edit, activate/deactivate, and configure each court.
- [ ] Empty state is shown when no courts exist.
- [ ] Only authorized administrators can view the courts of their complex.

## Business rules

- Courts belong to one complex.
- A court must have at least one active sport before it can accept reservations.
- Only authorized users can access resources they own or administer.

## Validations

- Validate the user is authenticated and authorized.
- Validate query parameters and pagination inputs.
- Return clear, structured error messages for invalid input.

## Error cases

- Invalid or missing input data.
- User is not authenticated or authorized.
- The referenced resource does not exist.
- No results match the filter criteria.

## Security considerations

- Authenticate and authorize every request.
- Do not expose internal implementation details in error responses.
- Avoid logging sensitive data such as passwords, tokens, or PII.
- Ensure users can only view data they are allowed to access (multi-tenancy).
- Verify the actor belongs to or administers the affected complex.

## Technical notes

- Use `GET /api/v1/complexes/{complexId}/courts`.
- Reuse `CourtInfo` contract.
- Implement table with Material-UI `DataGrid` or `Table`.
- Add search and pagination controls.
- Link each row to edit/availability pages.

## Tests required

- **Unit**: list rendering and pagination logic.
- **Integration**: API endpoint behavior and persistence.
- **E2E**: admin views court list and navigates to actions.

## Out of scope

- Advanced analytics, reporting, or notifications not required for the MVP.

- US-063 — Complex admin navigation layout.
