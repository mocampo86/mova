# US-071 — Search users and manage blocks from admin panel

## Status

Done

## Objective

As a complex administrator, I want to search users of my complex and manage blocks from the admin panel.

## Functional description

This user story enables the complex administrator to search users who have made reservations in their complex, view their reservation history, and block or unblock them from the admin dashboard. It belongs to EPIC-12 — Complex Admin Dashboard.

## Acceptance criteria

- [x] User search is implemented and available at `/admin/complex/:complexId/users`.
- [x] Results show users who have made reservations in the complex.
- [x] Results are filtered and paginated when applicable.
- [x] The administrator can view a user's reservation history.
- [x] The administrator can block a user with a reason and optional expiration.
- [x] The administrator can unblock a user.
- [x] A blocked user cannot create new reservations in the affected complex.
- [x] Blocks are scoped to a single complex.

## Business rules

- Search users of a complex.
- View user profile and reservation history.
- Block a user for a complex.
- Unblock a user.
- Optional expiration date for a block.
- Prevent blocked users from creating new reservations.
- A block in one complex does not affect the same user in another complex.
