# US-054 — See an audit log of administrative actions

## Objective

As a super administrator, I want to see an audit log of administrative actions.

## Functional description

This user story enables the super administrator to see an audit log of administrative actions. It belongs to EPIC-10 — Audit and Operations.

## Acceptance criteria

- [ ] See an audit log of administrative actions is implemented and available to the super administrator.
- [ ] Results are filtered and paginated when applicable.
- [ ] Only active and public resources are returned to unauthorized callers.
- [ ] Response times remain acceptable for mobile users.
- [ ] Administrative mutations (create/update complex, court, block, cancellation) are recorded in `AuditLog`.

## Business rules

- Audit log for administrative actions.
- Error monitoring and logging.
- Health checks and metrics.
- Basic operational documentation.
- Backup and recovery documentation.
- Rate limiting preparation on sensitive endpoints.

## Validations

- Validate required fields and data types server-side.
- Validate query parameters and pagination inputs.
- Return clear, structured error messages for invalid input.

## Error cases

- Invalid or missing input data.
- User is not authenticated or authorized.
- The referenced resource does not exist.
- No results match the filter criteria.

## Security considerations

- Authenticate and authorize every mutating request.
- Do not expose internal implementation details in error responses.
- Avoid logging sensitive data such as passwords, tokens, or PII.
- Ensure users can only view data they are allowed to access (multi-tenancy).

## Technical notes

- `AuditLog` entity: `Id`, `UserId`, `SportsComplexId`, `Action`, `EntityType`, `EntityId`, `CreatedAt`, `Metadata`.
- Use Serilog with correlation IDs propagated via `HttpContext`/`TraceIdentifier`.
- Application Insights for Azure; equivalent open-source alternatives for local/non-Azure environments.
- Rate limiting can be implemented with ASP.NET Core `RateLimiting` middleware.
- Keep audit logs immutable; do not update or delete audit records.
